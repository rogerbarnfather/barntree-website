Documentation

Everything Barntree does, task by task.

Barntree keeps a tree of things that follows the kinds of thing it may hold. You say what types of thing a subject has, and Barntree builds the tree from them and refuses any edit that would break the rules. A Tree can be about anything: the layers of a system, the rooms of a house, the modules of a course or the courses of a dinner. It is kept as plain JSON, so any language can read it.

The idea in five words #

  • Tree. The types of one subject, and the tree of items that follows them. Every example in this documentation is an allotment.
  • Template. A Tree kept in your project, to make Constructions from. It is the rules, and its skeleton.
  • Construction. A named tree of real members, made from a Template. It keeps the revision it started from.
  • Revision. One saved state of a Template or a Construction. None is ever changed.
  • Projection. A Tree shown another way: as text, a document, folders or a diagram.
