Glossary

Each word has one meaning across this site.

Barn #
A project with a .barn/ folder at its root. Barntree finds it from any folder inside the project.
Construction #
A named tree of real members, made from a Template. It keeps the Template revision it started from, and its own copy of the types.
Document id #
The id that identifies a Template or a Construction for good. It does not change when you rename it.
Glossary #
A Template’s view that puts every type and its meaning on one page. It shows only what was written.
Identifier #
What other types refer to a type by. It defaults to the name and never changes.
Item #
One element of the tree, following one type. It has an id that Barntree generates.
Kind #
What a type holds: leaf, list or map.
Leaf #
A type of nothing. An item of it holds nothing.
List #
A type of exactly one type. Its items hold members, any number, each with a name.
Map #
A type of a set of types, each at most once. Its items hold one item for each.
Meaning #
What a type is, in plain words, as long as needed.
Member #
An item in a list, with a name you give it. Members of one list have different names.
Projection #
A Template shown another way: as text, a document, folders or a diagram. It never changes the Template.
Revision #
One saved state of a Template or a Construction. Immutable. An explicit save that changes something records one.
Root #
The type the tree starts from, and its item. It can be of any kind.
Skeleton #
The starting tree: the root and every map entry below it, down to empty lists and leaves.
Snapshot #
A revision read as it was, read-only.
Source #
The Template revision a Construction was made from, which it keeps.
Tag #
A named label, with a meaning, that types in different places can carry.
Template #
A Tree kept in your project, to make Constructions from. It is the types and their skeleton, in one file.
Token #
A fingerprint of a Template’s exact current file, used to refuse a change based on a stale view. Not a revision id.
Tree #
The types of one subject, and the tree of items that follows them. Also, written small, the arrangement of items.
Type #
One kind of thing in a subject, with an identifier, a name, a meaning and a kind. The browser app and the command line call it a building block.
